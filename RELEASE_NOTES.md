Download `BatteryTray.exe` and double-click it. It installs itself: shortcuts on the desktop and in the Start menu, autostart, and an entry in Settings > Apps > Installed apps for uninstalling. No admin rights needed. If you already have 1.1.0 or newer, the program offers this update itself in the right-click menu.

Скачайте `BatteryTray.exe` и запустите двойным щелчком, программа установится сама. Если у вас уже стоит 1.1.0 или новее, она сама предложит обновиться в меню по правому клику.

Windows SmartScreen will warn because the file isn't signed with a paid certificate: "More info", then "Run anyway". / SmartScreen предупредит, что файл без платной подписи: «Подробнее», затем «Выполнить в любом случае».

What's new in 2.0.0:
- Razer Battery Tray is now called Battery Tray, since it shows Bluetooth, Logitech, DualShock 4 and HeadsetControl devices too. Updating from the menu moves everything over by itself: settings, the learned battery life, autostart and shortcuts; the old folder is removed. / Razer Battery Tray теперь называется Battery Tray. При обновлении из меню программа переезжает сама: настройки, автозапуск и ярлыки сохраняются, старая папка удаляется.
- `RazerBatteryIndicator.exe` below is the same program under the old name, for copies that update themselves from 1.x. For a new install take `BatteryTray.exe`. / `RazerBatteryIndicator.exe` нужен только для обновления старых версий, для установки берите `BatteryTray.exe`.
- Running the downloaded exe again while the program is open no longer fails silently now and then.

1.5.0 added the English interface, hiding devices from the menu, Bluetooth and DualShock 4 refreshed every minute, and cut the idle CPU to a third.

1.4.3 brought back notifications from other apps (Telegram and others) while the widget is running.

1.4.0 to 1.4.2 added Bluetooth devices of any brand, Logitech receivers, HeadsetControl headsets and DualShock 4 controllers; those were tested without real devices, so please report anything that looks wrong.
